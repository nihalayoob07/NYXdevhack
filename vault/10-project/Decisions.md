# Decisions

Format: date, decision, why, who.

### 2026-10-20: Engine decides, Claude explains
Feasibility, ranking and every number come from `engine.ts`. Claude's verdicts are overridden if they contradict the engine. Why: no made-up arrival times, and a strong answer to judges. (Raahil)

### 2026-10-20: Offline planner when there is no API key
Same steps and UI, explanations generated by the engine. Why: the live demo can never fail on stage because of the network or a key. (Raahil)

### 2026-10-20: Website first, native APK later
Next.js app in `web/` so a `mobile/` folder can sit next to it later. (Team)

### 2026-10-20: Layover means idle waiting time
Layover = gap between legs minus the transfer time the connection needs. Why: an early flight that lands four hours before the train really is a long wait for mum, but a 90-minute airport-to-station transfer is not waiting. (Raahil)

### 2026-10-20: Departure-board visual language
Dark and light themes, Geist + Geist Mono, one signage-yellow accent. Red only for broken links, green only for repaired ones. (Raahil)
